# 🐍 Python Mini Projects

A collection of beginner-friendly **Python projects and games** created to practice Python programming, logic building, functions, loops, conditions, user input, and external libraries.

## 📂 Projects Included

### 1. 🧮 Calculator

A simple calculator application that performs basic arithmetic operations such as:

* Addition
* Subtraction
* Multiplication
* Division

**File:**

```text
Calculator.py
```

---

### 2. 🔢 Number Guessing Game

A simple interactive game where the computer randomly selects a number and the player tries to guess it.

**Features:**

* Random number generation
* User input
* Hints for higher/lower guesses
* Number of attempts

**File:**

```text
NumberGuessing.py
```

---

### 3. 🔐 Random Password Generator

A Python program that generates random and secure passwords.

**Features:**

* Random characters
* Uppercase and lowercase letters
* Numbers
* Special characters
* Custom password length

**File:**

```text
RandomPasswordGenerator.py
```

---

### 4. ✊ Rock Paper Scissors

A command-line version of the classic **Rock Paper Scissors** game.

The player competes against the computer.

**Choices:**

* ✊ Rock
* 📄 Paper
* ✂️ Scissors

**File:**

```text
RockPaperScissors.py
```

---

### 5. 🐍 Snake Game

A classic Snake Game developed using Python and the **Pygame** library.

**Features:**

* Keyboard controls
* Snake movement
* Food generation
* Score tracking
* Game-over detection
* Increasing snake length

**File:**

```text
SnakeGame.py
```

### 📦 Required Package

The Snake Game requires the `pygame` package.

Install it using:

```bash
pip install pygame
```

Then run:

```bash
python SnakeGame.py
```

---

### 6. ❌⭕ Tic-Tac-Toe

A simple two-player Tic-Tac-Toe game developed using Python.

**Features:**

* Two-player gameplay
* 3 × 3 game board
* Winner detection
* Draw detection
* Input validation

**File:**

```text
TicTacToe.py
```

# 🚀 Getting Started

## 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/Python-Mini-Projects.git
```

Move into the project directory:

```bash
cd Python-Mini-Projects
```

## 2. Check Python Installation

Make sure Python is installed:

```bash
python --version
```

or:

```bash
py --version
```

## 3. Install Pygame

For the Snake Game, install Pygame:

```bash
pip install pygame
```

If `pip` doesn't work, use:

```bash
python -m pip install pygame
```

## 4. Run a Project

For example:

```bash
python Calculator.py
```

or:

```bash
python NumberGuessing.py
```

or:

```bash
python RandomPasswordGenerator.py
```

For Snake Game:

```bash
python SnakeGame.py
```

For Rock Paper Scissors:

```bash
python RockPaperScissors.py
```

For Tic-Tac-Toe:

```bash
python TicTacToe.py
```
